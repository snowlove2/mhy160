# 漫画160 · VeneraNext 漫画源

`mhy160.js` 是给 **VeneraNext 漫画阅读器**使用的 JavaScript 漫画源插件。它把「漫画160」网站的搜索结果、漫画详情、章节目录和图片地址转换成阅读器能够识别的数据，让用户在应用内搜索和阅读该站点的漫画。

仓库地址：<https://github.com/snowlove2/mhy160>。本仓库公开，无需登录 GitHub 即可下载脚本；也可以使用下面的原始链接直接导入阅读器。

脚本入口是 `class MH160 extends ComicSource`。文件名是 `mhy160.js`，应用内名称是「漫画160」，内部标识是 `mh160`；这三个名称各有用途。

它依赖应用提供的 `ComicSource`、`Network`、`HtmlDocument`、`Convert`、`Comic` 和 `ComicDetails` 接口，因此应当导入阅读器使用，不能直接用 `node mhy160.js`、双击文件或放进普通网页运行。无需单独执行 `npm install`。

## 能做什么

| 功能 | 实际行为 |
| --- | --- |
| 在线搜索 | 将关键词发送到站点 `/statics/search.aspx?key=...`，解析真实搜索结果；去掉关键词首尾空白，编码中文和特殊字符，并按漫画 ID 去重。 |
| 漫画详情 | 获取作品名称、封面、简介及 `chapterList_ul_1` 中的章节。 |
| 章节阅读 | 解析章节页中的 Base64 图片路径，按 UTF-8 解码，再生成完整图片 URL。 |
| 阅读顺序 | 将站点从新到旧的目录反转，返回从旧到新的章节顺序；章节键使用 `ep_` 前缀保留插入顺序。 |
| 探索页 | 提供「常用直达」和能够成功解析时的「首页推荐」。 |
| 直达作品 | 当前内置《中国惊奇先生》，漫画 ID 为 `15111`。 |
| 图片请求 | 为正文图片和封面分别设置 `Referer`，满足站点的图片请求要求。 |
| 图片域名设置 | 提供「自动」及多个手动域名选项，方便遇到图片加载问题时更换。 |
| 网站链接识别 | 识别 `mh160mh.com`、`www.mh160mh.com`、`m.mh160mh.com` 下带 `/kanmanhua/{id}/` 的链接，并提取漫画 ID。 |
| 验证页识别 | 识别部分 Cloudflare 质询页，把错误交给阅读器处理；验证页面和 Cookie/UA 管理由宿主应用完成。 |

「常用直达」只是在本地生成一个已知作品入口。打开漫画详情、加载封面和阅读章节仍然需要联网。

## 安装和开始使用

### 通过文件导入

1. 下载本仓库中的 **`mhy160.js` 文件本身**。如果下载的是仓库 ZIP，先解压后再选择该文件。
2. 打开 VeneraNext 的「漫画源」管理页面，使用文件导入或「添加来源」中的文件入口。
3. 选择 `mhy160.js`，识别或预览后安装。成功后，源列表中应出现「漫画160」。不同应用版本的按钮名称可能略有差异。
4. 在搜索时选择「漫画160」，输入漫画名称；也可以从探索页的「常用直达」进入《中国惊奇先生》。
5. 打开作品详情，选择章节阅读。

已经安装相同 `key = "mh160"` 的脚本时，使用应用提供的替换、更新或重新加载入口。维护脚本时应保持这个标识稳定，以便应用继续关联该源的收藏和历史。

### 通过原始链接导入

可以使用以下 GitHub **Raw 原始文件地址**导入：

```text
https://raw.githubusercontent.com/snowlove2/mhy160/main/mhy160.js
```

以上地址对应本仓库的 `main` 分支。`github.com/.../blob/...` 是文件展示页，会返回 HTML，应从文件页面的 Raw 入口取得脚本下载地址。

此链接无需 GitHub 登录或令牌。使用阅读器的单脚本链接入口，粘贴上面的完整地址，再按应用流程识别并安装。

### 通过源列表导入

本仓库另外提供 `index.json`，其中登记了脚本名称、标识、版本和相对文件名。支持源仓库列表的应用版本可导入它的原始链接：

```text
https://raw.githubusercontent.com/snowlove2/mhy160/main/index.json
```

源列表链接同样无需 GitHub 登录。如果当前应用只提供文件或单脚本链接入口，直接导入 `mhy160.js` 即可。

## 图片域名怎么设置

在该漫画源的设置中找到「图片资源站域名」。默认值是「自动(推荐)」。

| 设置 | 选择规则 |
| --- | --- |
| 自动，章节页 `qTcms_S_p_id > 542724` | 使用 `xwdf.tgmhfc.uk`。 |
| 自动，章节页 `qTcms_S_p_id <= 542724` | 使用 `mhpic6.tgmhfc.uk`。 |
| 手动选择域名 | 对当前加载的章节统一使用选定域名，覆盖上述分流规则。 |

可手动选择的域名有：`xwdf.tgmhfc.uk`、`mhreswhm.tgmhfc.uk`、`qwe123.tgmhfc.uk`、`resmhpic.tgmhfc.uk`、`reszxc.tgmhfc.uk`、`mhpic7fr.tgmhfc.uk` 和供老章节使用的 `mhpic6.tgmhfc.uk`。

**当前「自动」没有域名探测或失败后自动轮换功能。** `newHosts` 虽然列出多个新域名，自动模式实际只使用数组的第一个。切换域名后，重新打开章节或触发图片重试；若应用仍显示缓存结果，需要使用其重新加载功能。

正文和封面都会带上：

```http
Referer: https://m.mh160mh.com/
```

因此在浏览器中单独粘贴图片地址的结果，不一定等同于阅读器内的加载结果。图片域名设置仅影响章节图片，封面仍使用网页提供的地址。

## 搜索和 Cloudflare 验证

搜索始终请求站点，不会用「常用直达」代替在线结果。如果验证失败、请求超时、HTTP 状态异常或搜索页面结构改变，脚本会向应用报告错误。

脚本会检查 `cf-mitigated: challenge` 响应头，以及 `Just a moment`、`Attention Required` 标题、`_cf_chl_opt`、`challenge-form` 等页面特征。识别后抛出 `CloudflareException: <页面地址>`，让支持该机制的阅读器显示验证入口。

若应用出现验证按钮或提示，按应用流程完成验证，再重试原来的搜索。这个插件负责识别和上报质询页，验证是否可完成取决于应用版本、站点响应和当前网络环境。

## 当前局限

- **搜索只实现一页结果。** 返回值固定为 `maxPage: 1`，请求第二页及之后的页码直接返回空列表，没有实现分页、排行或搜索筛选。
- **依赖站点 HTML 格式。** 搜索依赖 `#listbody`；目录、首页推荐和章节变量主要通过正则解析。站点修改布局、属性顺序、引号或变量格式后，可能需要更新代码。
- **只读取一个目录容器。** `chapterList_ul_1` 之外的章节分组没有被解析；无法匹配目录时当前会返回空章节对象。
- **缺少图片路径时返回空图片数组。** 没有专门为变量缺失、路径格式改变或解码后没有图片的情况提供更具体的错误提示。
- **章节分流编号缺失时按旧域名处理。** `qTcms_S_p_id` 无法匹配会得到 `0`。
- **未实现站点账号、网络收藏、评论和评分接口。** 应用自身的收藏、缓存、下载等能力由阅读器管理。
- **未返回作者标签和更新时间。** 详情中的 `tags` 是空对象，也没有 `updateTime`；依赖这些字段的追更或筛选功能没有由该脚本提供完整数据。
- **未配置脚本在线更新 URL。** 当前可下载新版文件后重新导入；通过仓库列表更新是否可用，取决于宿主的仓库支持。若要补充 `url`，应填写可直接读取 JS 的真实原始地址。

## 常见问题

| 现象 | 原因和处理方向 |
| --- | --- |
| `ComicSource is not defined` | 脚本被放在普通 JS 环境运行；应导入 VeneraNext。 |
| 导入提示格式错误 | 确认下载的是原始 JS，文件内容以注释和类声明开头，而非 GitHub HTML 页面；核对应用的漫画源接口支持。 |
| `CloudflareException` 或显示验证入口 | 在阅读器中完成网页验证，再重试；脚本不会自行完成验证。 |
| 「漫画160 搜索页面格式变化，请更新漫画源」 | 页面缺少预期的 `#listbody`；检查返回的是否为正常搜索页，必要时调整解析逻辑。 |
| 没有搜索结果 | 正常的空 `#listbody` 会返回空列表；超过第一页也会返回空列表。若请求失败，应查看应用报告的错误。 |
| 详情能打开，但图片 404 或加载失败 | 核对新旧章节域名及图片 `Referer`，尝试其他图片域名，再重新加载。 |
| 切换图片域名后封面仍失败 | 封面使用网页中的独立地址；图片域名选项没有修改封面地址。 |
| 「常用直达」能显示，但打开作品失败 | 入口数据来自内置索引，详情和章节仍依赖网站访问。 |
| 目录为空或章节内容为空 | 可能未匹配到目录 HTML 或章节 `url_e`；检查网页结构是否变化。 |
